# Зарубіжна література, 6 клас — матеріали для уроків

Основа: підручник Ю. Ковбасенка, О. Первака, С. Дячок (Літера ЛТД, 2023).

## Структура
- `course_index.json` — карта курсу: теми, уроки, сторінки підручника і PDF.
- `lessons/NN.md` — тема: мета, поняття, матеріал для пояснення, стислий зміст твору, запитання й завдання з нумерацією підручника.
- `tests/NN.json` — інтерактивний тест до теми.

## Важливо
- Сторінка PDF = сторінка підручника + 1.
- Повні тексти творів і дослівні формулювання завдань не дублюються: завдання подано стисло зі збереженням номерів і сторінок. Для читання твору застосунок показує відповідні сторінки PDF (`pdf_pages`).
