# Українська мова, 6 клас — матеріали для уроків

## Структура
- `course_index.json` — карта курсу: параграфи, розділи, сторінки, файли.
- `lessons/pN.md` — параграф: стисле правило з прикладами, перелік вправ підручника (номер, сторінка, тип), посилання на тест.
- `tests/pN.json` — інтерактивний тест.

## Важливо
- Сторінка PDF = сторінці підручника (зсуву немає).
- Параграфи з позначкою QR у підручнику подано лише за QR-кодом; у файлах вони позначені `type: qr`.
- Тексти вправ, диктантів і правил дослівно не дублюються: правило викладено стисло, а вправи подано номером, сторінкою й типом. Для виконання вправи репетитор показує відповідну сторінку PDF.
- Мовленнєвий практикум (§§ 126–131) доступний лише онлайн за покликанням у підручнику.
