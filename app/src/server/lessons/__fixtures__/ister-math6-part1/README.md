# Математика, 6 клас — Істер, 2023, частина 1

Пакет для імпорту уроків і тестів у навчальний додаток. Охоплено **всю надану частину 1: § 1–25**, повторення за 5 клас і двох розділів, усі 5 домашніх самостійних та 5 перевірочних робіт. Друга частина до наданого PDF не входить.

## Швидкий початок

1. Розпакуйте архів зі збереженням папок.
2. Для перегляду відкрийте **preview.html** у браузері. Уроки, рисунки, формули та автоматичні тести працюють без інтернету.
3. Для імпорту прочитайте **manifest.json**, потім **lessons.jsonl**, **exercises.jsonl** і **tests.jsonl**. Один рядок JSONL — один об’єкт JSON.
4. Скопіюйте папку **assets/** у сховище додатка. Усі шляхи в JSON задано від кореня архіву. У Markdown шляхи відносні до конкретного файла.

## Як збережено математику

Основні сторінки наданого PDF — скани без текстового шару. Тому **точним джерелом умов, формул і повного матеріалу підручника є оригінальні зображення WebP без втрат**. Вони вставлені в Markdown та прив’язані до тем і вправ у JSON. Повні сторінки дають контекст, зокрема коли рисунок розташований поряд із кількома вправами.

`search_text_ocr` — допоміжний розпізнаний текст. Він **не є вичитаною транскрипцією**, особливо для дробів, степенів, знаків і таблиць. Його не слід показувати як точну математичну умову або використовувати як ключ оцінювання. Умови для ШІ-репетитора передавайте разом із зображенням. Якщо репетитор працює лише з текстом, потрібна додаткова ручна транскрипція відповідних формул.

`teacher_notes_md` — коротке окреме пояснення для уроку, а не заміна чи дослівний переказ усього тексту підручника. Формули цих пояснень і 140 додаткових питань записані в LaTeX. В оригінальних фрагментах збережені повні пояснення, приклади, запитання та вправи книги.

## Перевірка відповідей

- `automatic_questions` — 140 додаткових питань з одним правильним варіантом, ключем і поясненням. По 5 до кожного параграфа та кожного повторення.
- `source_exercise_ids` — оригінальні вправи теми. Вони потребують перевірки вчителем або репетитором; повні автоматичні ключі до них не додані.
- 10 оригінальних самостійних/перевірочних робіт збережено як окремі модулі з незміненою нумерацією. Їхні формулювання й варіанти відповідей містяться в оригінальних зображеннях.
- Відповіді та поради, які наведені самим автором підручника, збережені окремо в `source/answers.*`; їх не домислювали для вправ без авторського ключа.

## Масштаб і вимірювання

Для завдань, де потрібно вимірювати рисунок або карту, зберігайте фізичний масштаб. `assets/index.json` містить `physical_width_mm`, `physical_height_mm`, `bbox_pt`, `width_px` і `height_px`. Один PDF point дорівнює 1/72 дюйма. Роздільність растеризації — 180 dpi (2,5 px/pt).

На екрані міліметри CSS не гарантують фізичної точності через масштаб браузера та характеристики дисплея. Для вимірювання лінійкою друкуйте рисунок або оригінальну сторінку у масштабі 100 %, без «вмістити на сторінку», або реалізуйте в додатку вимірювання за координатами та метаданими. Не визначайте реальну довжину за довільно масштабованим прев’ю.

## Походження

Джерело — наданий користувачем файл `6-klas-matematyka-ister-2023-1.pdf`, 210 PDF-сторінок. Для включених навчальних сторінок номер сторінки PDF збігається з друкованим номером. SHA-256 вихідного файла наведено в `manifest.json`.

Оригінальні фрагменти підручника позначено `origin: textbook`; авторські пояснення та додаткові тести — `origin: teacher_adaptation`. Зображення не перемальовувалися. Для автономного перегляду формул включено KaTeX 0.16.11; його ліцензія міститься в `assets/vendor/katex/LICENSE`.
