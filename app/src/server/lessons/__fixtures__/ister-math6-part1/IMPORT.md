# Формат імпорту v1.0.0

Кодування всіх текстових файлів — UTF-8. JSONL складається з окремих JSON-об’єктів, по одному на рядок. У файлах немає прив’язки до конкретної бази даних або постачальника ШІ.

## Порядок імпорту

1. Прочитати `manifest.json`; перевірити `schema_version`.
2. Завантажити всі ресурси з `assets/index.json`, зберігши відносні шляхи або створивши таблицю відповідності `path → URL`.
3. Імпортувати `exercises.jsonl`, використовуючи `id` як унікальний ключ.
4. Імпортувати `lessons.jsonl`, зберегти порядок поля `order` і зв’язки `exercise_ids`.
5. Імпортувати `tests.jsonl`; зв’язати кожен тест із `lesson_id`.
6. Додати ресурси `source/answers.json`, `source/reference.json` за потреби.
7. Запустити `python3 tools/validate_import.py` з будь-якої робочої папки. Скрипт використовує лише стандартну бібліотеку Python.

Окремі JSON у `lessons/` і `tests/` містять ті самі об’єкти, що й відповідні JSONL. Не імпортуйте обидва варіанти одночасно як різні записи.

## Урок

| Поле | Значення |
|---|---|
| `id` | Сталий ключ: наприклад `p03`, `review_1`, `homework_2` |
| `order` | Порядок у підручнику, 1–38 |
| `kind` | `lesson`, `review` або `assessment` |
| `source.paragraph` | Оригінальний номер параграфа або `null` для окремих рубрик |
| `source.printed_pages` | Масив усіх сторінок, на яких розміщена тема |
| `source.start`, `source.end_exclusive` | Межі теми всередині сторінки, в PDF points |
| `teacher_notes_md` | Коротке перевірене пояснення у Markdown/LaTeX; адаптація |
| `source_material` | Упорядковані фрагменти повної оригінальної теорії, прикладів і запитань перед вправами |
| `exercise_ids` | Вправи теми в початковій послідовності |
| `full_page_image_paths` | Повні сторінки теми для контексту |

Дві теми можуть починатися/закінчуватися на одній сторінці. Орієнтуйтеся на фрагменти та межі, а не лише на діапазон сторінок.

## Вправа

Унікальний ключ: `p23_ex_797`. Номер, який слід показувати дитині: **797**, із поля `original_number`.

`content` — упорядкований масив блоків. Кожен `source_image` містить `path`, координати `source.bbox_pt`, номер сторінки, `page_image_path` та `search_text_ocr`. Якщо задача переходить на наступну сторінку, у неї кілька блоків. Виводьте всі блоки в порядку масиву.

`figure_ids` і `figure_paths` — додаткові повні рисунки, зокрема з інших сторінок. Вони можуть повторювати рисунок у фрагменті умови: це зроблено для окремого масштабування і для усунення обрізання, коли рисунок розташовано поряд із кількома номерами.

`grading.mode: manual_or_tutor_review`, `answer_key: null` означають, що автоматичний ключ не створено. Це **не** означає, що правильна відповідь — порожня або `null`.

## Автоматичне питання

```json
{
  "id": "p01_q01",
  "type": "single_choice",
  "origin": "teacher_adaptation",
  "prompt_md": "Текст питання з $LaTeX$",
  "options": [
    {"id": "A", "text_md": "Варіант A"},
    {"id": "B", "text_md": "Варіант B"}
  ],
  "correct_option_id": "B",
  "explanation_md": "Пояснення відповіді",
  "max_points": 1
}
```

Приклад показує структуру, а не реальне питання; фактичні питання мають чотири варіанти. Порівнюйте обраний `option.id` із `correct_option_id`. Не порівнюйте тексти варіантів. Якщо перемішуєте варіанти, зберігайте їхні `id`. Відповідь оцінюється в 1 бал, інша або пропущена — у 0. `automatic_max_points` — максимальна сума для цього тесту.

Ключі та пояснення показуйте після відповіді або в режимі вчителя. Власні номери автоматичних питань не замінюють номерів оригінальних вправ.

## Відображення формул і зображень

У `*_md` використано `$...$` для формул у рядку. Підтримуються KaTeX/MathJax. У JSON зворотні слеші екрановано за стандартом JSON; після `JSON.parse` додаткове розекранування не потрібне.

Для кожного зображення є відносний шлях і `alt`. Зберігайте співвідношення сторін; для задач на вимірювання використовуйте фізичні розміри. Зображення — WebP без втрат, без потреби у зовнішніх URL.

## Використання ШІ-репетитором

Передавайте репетитору назву теми, `teacher_notes_md`, зображення відповідної умови, додаткові `figure_paths` та, за потреби, повну сторінку. `search_text_ocr` можна використовувати для пошуку вправи, але не як достовірну транскрипцію дробів чи виразів. Перед оцінюванням оригінальної задачі репетитор має прочитати саме зображення й виконати розв’язання; наявний авторський розділ відповідей можна використати для звіряння.
