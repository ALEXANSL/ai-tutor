# ШІ-Репетитор — стартовий набір агентів для Claude Code

## Що всередині
- `CLAUDE.md` — «пам'ять» проєкту: правила, процес, команда агентів. Claude Code читає його автоматично.
- `.claude/agents/` — п'ять агентів: product-manager, architect, designer, developer, qa-tester.
- `docs/00-product-brief.md` — ваші вимоги, зібрані з нашої розмови. Відкрийте й допишіть **[TBD]** (клас доньки, предмети).

## Як запустити
1. Встановіть Claude Code (найпростіше — вкладка Code в десктопному застосунку Claude). Бажано на особистому, а не корпоративному комп'ютері.
2. Створіть приватний репозиторій на GitHub (наприклад `ai-tutor`) і склонуйте його в папку на комп'ютері (Claude Code може зробити це за вас — просто попросіть).
3. Розпакуйте вміст цього архіву в корінь папки проєкту (папка `.claude` прихована — перевірте, що вона скопіювалась).
4. Відкрийте папку в Claude Code і напишіть:
   > Прочитай CLAUDE.md і docs/00-product-brief.md. Запусти Фазу 0 з агентом product-manager і постав мені відкриті питання.
5. Відповідайте на питання, затверджуйте кожну фазу. Далі:
   > Вимоги затверджую. Запускай Фазу 1 з architect.

## Корисні команди-підказки
- «Покажи статус проєкту» — оркестратор прочитає `docs/STATUS.md`.
- «Запусти qa-tester для останнього зрізу».
- «Поясни простими словами, що зробив developer і як мені це перевірити».
