# Щоденник: тижневий розклад

Єдина школа використана як UX-орієнтир: день = колонка, номер/час = рядок, компактна картка = предмет + тема + ДЗ. Оцінки не копіюються й не вигадуються. Мобільний вигляд показує один день і всі кнопки днів без горизонтальної прокрутки. На широкому екрані заголовки колонок залишаються видимими в області прокрутки. Недільна колонка додається лише за наявності даних або поточної неділі.

Урок і всі його домашні завдання об’єднано за appointmentId. Повні умови, строки, посилання на підготовлений урок, статус виконання та батьківська ручна прив’язка доступні у native dialog. «ДЗ ✓» означає виконання в репетиторі, а не здачу в школі. Список ДЗ за строками з усіма попередніми фільтрами залишено окремим виглядом. Є навігація тижнів, «Сьогодні», пошук та перехід до останнього імпортованого тижня.

Помічник додає лише реальні LessonNumber, StartTime, RoomNumber у необов’язковий schedule. Контракт v1 і попередні JSON залишаються сумісними. Старі записи без часу відображаються без вигаданих годин; для точного розкладу треба оновити розширення/закладку й повторно синхронізувати. Збагачення лише schedule не позначає виконані ДЗ зміненими. Учнівські імена, оцінки, cookies, токени та URL вкладень не передаються. Нових платних AI-викликів чи міграцій немає.

Перевірки: 2216 unit-тестів повного набору; додані сценарії дат на межі року, групування, сумісності старого пакета, enrich без втрати статусу, часу з collector, dialog/navigation/list для дитини та батька. Chromium: 320/390/768/1440 × light/dark × child/parent, без overflow, перемикання дня, діалог, навігація тижня, попередній список. Візуальний огляд desktop/mobile. Дані браузерної перевірки синтетичні; приватної шкільної сесії немає.
