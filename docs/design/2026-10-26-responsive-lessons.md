# Урок на смартфоні

PO: навігація займає майже весь екран телефона. Причина: багаторядкова fixed toolbar, успадковані кнопки 56 px, дубльовані виходи, плаваючі theme/parent controls і нижній рядок, що переноситься.

Компактний режим: ширина до 1023 px або висота до 520 px. Верхня смуга близько 56 px: тривога, коротка назва, меню. У меню — вихід, список уроків, попередній/наступний урок, зміст, відео, голосові перемикачі, тема оформлення; один набір контролів, без скидання їхнього стану при відкритті. Меню прокручується в межах екрана. Поза меню контент залишається основною частиною viewport.

Нижня панель — один рядок: назад, номер кроку, підручник, далі. Touch targets від 44 px; текст підручника в компактному режимі візуально замінюється книжковою піктограмою зі збереженням accessible name. Parent mode залишається досяжним як окрема компактна кнопка з зарезервованим місцем. Theme toggle переноситься до меню тільки на compact lesson screen. На планшеті/desktop з достатньою висотою залишається розгорнуте керування. Safe areas і збільшення шрифту не повинні створювати накладання.

Це зміна спільних navigation components і CSS, без змін контенту уроків, порядку, прогресу, аудіо API чи імпорту. Приймання: 320/360/390/412 px, landscape 844×390, tablet 1024×768, desktop; menu open/close/Escape, читабельний текст, відсутність горизонтального scroll/перекриття нижніх дій parent mode.
