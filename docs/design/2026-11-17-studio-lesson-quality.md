# Повноцінний урок із презентації та повне озвучення

Аудит виявив конкретні обмеження: full-source шлях тільки до 30 chunks, після чого fallback search 8; PPTX на 32 слайди/11504 символи тому не передавався автору повністю. Автор обмежений 4–8 блоками й 24000 символами text+narration; narration має менший ліміт (3500 проти4500). Default план/автор/рецензія — low effort; текст і голос формуються незалежно. Publisher сам додає Sources screen з enrichmentNote, references, adultAssistance. TTS helper обрізає input/hash на4000 символів. Це інструкції/контракти застосунку, не доведений дефект GPT.

Рішення: до200 fragments/55000 UTF-8 bytes JSON (із metadata) для цілого невеликого джерела з явною відмовою для завеликого document без silent retrieval fallback; service/reference source annotations лишаються батьку. План формує теми/опору на sources; автор покриває основні навчальні теми, розвиває пояснення й приклади, адаптує практику. Тривалість — орієнтир, не причина тихо втратити теми. Технічна місткість до24 блоків, не квота. Stored lesson/schema backward-compatible; new author може повернути narration=null для українського text, сервер створює повне озвучення з видимого тексту. Code/native-language narration зберігає власний адаптований сценарій. Нова генерація не дублює весь український text у JSON двічі. Рецензент перевіряє реальне покриття тем, повноту озвучення і відсутність службових сторінок.

Default quality routes plan/author/review отримують окремі *_full role keys (medium effort, більша bounded output місткість); наявні custom legacy маршрути успадковуються, старі routes не перезаписуються. Усі виклики резервуються у чинному project cap/family budget. Ручна доопрацювання проєкту з materialId оновлює sources з бібліотеки перед новим платним викликом; не треба перезаливати PPTX. Попередня опублікована версія зберігається до republish.

Publication більше не створює службовий Sources screen; provenance лишається в parent preview. Застереження щодо небезпечної практики залишаються дитині в навчальному контексті. Старі source screens не видаляються з БД при rerelease, новий flow їх не включає. IDs наявних навчальних блоків/квізів стабільні.

V3 narration читає довгий text послідовними частинами <=3500 символів, кожна з власним cache field; перехід до наступного кроку тільки після останньої частини. Навігація/voice-off скасовують поточну й очікувану озвучку. Не склеюємо MP3 і не змінюємо глобальний TTS контракт інших readers. Текст не відсікається до4000 для цих V3 parts.
