# Аудит презентації «Цифровий слід»

Наданий PPTX: 11 слайдів, 5 raster media, 4 слайди з infographic; слайд 3 — лише одна теза як автоматичне продовження слайда 2. Рендер LibreOffice/PDF підтвердив порожні картки (назви без detail), однакову темну шапку на всіх слайдах та слабке використання площі. Причина: cap=4 умовні рядки на слайді зі схемою + raster visual малює тільки label, detail є лише в notes. Не проблема початкового тексту чи відсутності PowerPoint.

Виправлення: окремий титульний макет, контентні картки, редаговані native PowerPoint-схеми з label+detail, боковий блок тез, контрастний підсумок і послідовна навігація/кольори. Числові графіки зберігають перевірений raster renderer. Підвищений бюджет тексту для visual-слайдів прибирає сирітські продовження коротких тез. Native table pagination та всі speaker notes зберігаються. Це дизайн експортера; перепідготовка ШІ не потрібна, повторне скачування вже збереженої роботи використовує новий експортер. Растрові фото/генеровані картинки в homework artifacts залишаються окремим наступним контрактом; не видаємо схеми за фото.
