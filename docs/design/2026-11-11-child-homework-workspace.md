# Домашнє завдання в інтерфейсі дитини

Погоджений сценарій: дитина формулює запит, вказує сторінку/номер або вставляє текст завдання; результат — у чаті, DOCX або PPTX. Готові відповіді, пояснення, вільний текст, реферати, задачі й проєкти без примусового режиму підказок. Уточнення та перероблення в діалозі. Урок — контекст, не межа знань; джерела відділено від доповнень ШІ.

## Реалізація

- Кнопка «Домашнє завдання» у спільній панелі репетитора всіх підтримуваних типів уроків. Окрема сторінка; «До уроку» та «На головну» завжди доступні. Список робіт цього уроку, промпт до 20 000 символів, формат, сторінки, PDF/PNG/JPEG/WebP/TXT.
- Контекст/предмет/тема визначаються сервером за voice target з перевіркою family/child/access. Шляхи й тексти джерел із браузера не довіряються. Доступні матеріали підбираються сервером; якщо потрібного завдання немає, ШІ просить джерело, не вигадує.
- Роботи/діалог — versioned jobs document окремого типу з child id, lesson identity, CAS revision, idempotent request id. Next.after виконує генерацію після відповіді; running/ready/failed, polling і відновлення сторінки. Невизначений збій не запускає автоматичний повтор платного запиту; готовий результат зберігається.
- Використовуються OpenAI через lesson_tutor, загальний router/бюджет/журнал витрат, модерація текстового запиту й правила дитини. Ключів у браузері немає. Попередній результат та історія передаються для доопрацювання.
- Структурована відповідь: повідомлення, матеріал DOCX/слайди PPTX або уточнення, поради для пояснення роботи. Без довгої обов’язкової анкети; дитина може просити готовий результат.
- DOCX/PPTX збирає сервер без HTML від моделі, macros чи довільних URL. Повторне завантаження — без виклику ШІ. Довгі тези PPTX розбиваються на додаткові слайди; зберігаються нотатки доповідача. Перший реліз — редаговані текстові презентації з оформленням, без обіцянки генерованих фото/відео.
- Власні вкладення тимчасові: оригінальні файли не зберігаються; лишається назва й відповідь. Для наступного запиту файл за потреби додається знову. Сторінки підручника отримуються сервером.

## Приймання

Урок → нове завдання → уточнення/робота → доопрацювання → повторне відкриття → експорт. Перевірити XML DOCX/PPTX, українські символи, пагінацію/слайди, нотатки, ownership, CAS/idempotency, бюджет/модерацію, відновлення й responsive 320/390/768/1440. Не змінювати оцінки/прогрес уроку. Міграція БД не потрібна. Фоновий процес обмежений одним викликом до 90 с; втрата worker виявляється після lease, без прихованого повтору.

## Витрати й підтвердження

Реалізація використовує вже налаштовану OpenAI-роль lesson_tutor, router/журнал ai_calls і загальний бюджет родини. Ліміт виходу береться із налаштувань цієї ролі (default 6000 tokens). Експорт DOCX/PPTX не викликає ШІ; повторне відкриття/завантаження готової роботи теж. Уточнення/доопрацювання — новий оплачуваний model call; модерація працює за наявним механізмом. Наявні ціни й моделі власника не перезаписуються.

Локальних production-секретів для живих платних генерацій немає. QA використовує mock AI/auth/store, синтетичні TXT/PDF і справжній DOCX/PPTX export. Кошти на живі генерації не витрачались, фактичні рахунки/приватна БД не читалися. Підтвердження тарифів ролі — наявна конфігурація проєкту; нові бібліотеки відкриті, нової підписки не потребують.
