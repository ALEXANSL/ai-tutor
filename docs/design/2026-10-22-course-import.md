# Завантаження курсу: один архів

Основна дія одна: вибрати предмет і готовий ZIP. Три видимі етапи пояснюють стан без технічних термінів: обрати → перевірити → додати. Перед записом показано назву й чотири лічильники: уроки, завдання, ілюстрації, PDF. Попередження мають окремий блок; успіх із зауваженнями не виглядає як безумовний успіх.

Форма використовує наявні батьківські кольори, округлі картки, контрастні основні кнопки й цілі натискання від 44 px. На вузькому екрані поля та кроки стають вертикальними. Старі форми згорнуті, додавання окремої книги винесене в другорядну дію. Промпт можна скопіювати, відкрити або завантажити.

Для наступного покращення дитячого UI пріоритет — ясна ієрархія й відчутний стан репетитора: слухає / думає / говорить, короткі абзаци, читабельні картки вправ, одна основна дія на кроці. Продовжуємо напрям [дослідження](../09-ui-ux-teen-research.md): стриманий підлітковий стиль, без примусу до серій днів чи надлишку анімації. Нових відео, персонажів або перестановки малюнків цей зріз не додає.

Перевірка: синтетичний стан після preflight, реальний компонент і production CSS, Chromium, 412/1200 px, світла/темна теми, без горизонтального переповнення. Фізичний планшет і реальний авторизований upload не перевірялися.
