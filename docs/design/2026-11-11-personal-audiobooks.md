# Особиста бібліотека й аудіокниги — перший робочий зріз

Власник авторизував реалізацію 2026-11-11. Нові оригінали не копіюються до сховища платформи: читання наявного матеріалу з Google Drive у пам’яті, після запиту bytes не зберігаються. Чинний індекс chunks уже зберігає текст: це явно зазначено в UI, старі дані автоматично не видаляються.

Каталог для тата й дитини: назва, автор (редаговані бібліотечні метадані), розділи, пошук тексту. Розділ або PDF-сторінки — явний точний вибір; друковані сторінки доступні тільки після підтвердження зсуву нумерації. EPUB має розділи, не фіктивні друковані сторінки. Зміст наявного індексу + ручні правки; EPUB-зміст можна перечитати з оригіналу без ШІ.

Одна підготовка охоплює до 50 фізичних сторінок/одиниць і 60 000 символів. AI редактор лише позначає технічні абзаци до вилучення, не переписує твір. Безумовне збереження авторських слів/діалогів/віршів; текст і перелік вилучень доступні татом до погодження. Неповні/нерозбірливі сторінки відхиляються до paid call; індексні chunks з overlap не читаються як суцільний оригінал. OCR/переклад — наступні окремі зрізи.

Довговічні документи audiobook.book / audiobook.part / audiobook.position у чинній jobs (status done: не generic runnable jobs); family scope, revision CAS, paid-call reservation, lease/token й явний retry. Це не нова SQL-схема; future jobs cleanup мусить виключати ці документи. Збереження очищеного сценарію та аудіо явно погоджується. Частини аудіо — до 2800 символів, private bucket, hash від exact text+model+voice+version, повторне відтворення без AI. Бюджет на частину книги, глобальний бюджет router; невизначений виклик зберігає резерв і не повторюється автоматично. Перевірені route/rates на весь виклик.

Підготовка → перегляд сценарію → погодження озвучення → фонова генерація частин → публікація/приховування дитині. Паузи, видалення власного результату з підтвердженням (не оригіналу/індексу), плеєр зі швидкістю, перемотуванням, закладкою і позицією між пристроями. Вибір дитини не запускає оплачувану генерацію. Голосові команди бібліотеки — окрема явна панель пошуку/переходу без відправки повної бібліотеки репетитору; наявні lesson tutor tools не підміняють точне читання вигаданим текстом.

Тести без платних live API та приватної production-бази. Якість реального українського голосу/очищення першого розділу оцінюється в preview. OpenAI TTS-1-HD має покомпонентну ціну за символи, не приблизну конвертацію токенів; звірити офіційну ціну перед активацією. Немає нових підписок/міграцій, витрат цієї сесії на генерацію.

## Реалізація та межі

Батьківський каталог `/parent/library`, книга `/parent/library/books/[id]`, підготовка `/parent/audiobooks/[id]`; старий `/parent/library/[id]` (методичний паспорт уроку) збережений. Дитячі `/library`, `/library/[id]`, `/audiobooks/[id]`. Меню уроку містить перехід у бібліотеку та зворотне посилання з валідацією внутрішнього шляху.

Оригінальний PDF читається лише по вибраних фізичних сторінках із межами рядків/абзаців. EPUB перевіряється за сумарним розпакованим обсягом перед обробкою; його частини й назви отримуються зі spine/TOC. Метадані бібліотеки доповнюють чинні materials/material_sections; свідомо порожній ручний зміст не замінюється старим автоматичним. Пошук читає тільки наявний індекс chunks з сімейною перевіркою, без embedding/API витрат, включно з книгами, вимкненими для уроків. Якщо книга ще не проіндексована, працює пошук за метаданими/розділами та озвучення з оригіналу, але не повнотекстовий пошук. Старе завантаження у «Мої книги» зберігає чинну автоматичну індексацію; окремого нового upload pipeline тут немає.

TTS — окрема OpenAI-only роль audiobook.narrate, default tts-1-hd, $30 / 1M characters. Звірено https://developers.openai.com/api/docs/models/tts-1-hd та https://developers.openai.com/api/docs/pricing/ 2026-11-11. Технічний редактор — audiobook.prepare / GPT-5.4. Конфігурація/ціна фіксуються на платний виклик; запис ai_calls й глобальний бюджет чинні. Голоси Nova/Alloy/Onyx; назва голосу/модель/точний текст включені в hash. Аудіо кешується для конкретної підготовки, не глобально між різними сім’ями/виданнями/діапазонами. На плеєрі попередньо завантажується наступний фрагмент, немає монолітного файлу книги. Storage віддає Range по короткому signed URL; draft preview має окремий parent-only маршрут. Позиція/швидкість/одна закладка зберігаються для авторизованого користувача між пристроями.

Голосовий запит у бібліотеці — явний запис до 15 с через наявний OpenAI Whisper; витрати у загальному бюджеті. Пошук точного розділу/діапазону відкриває тільки вже підготовлене аудіо, не довільний сусідній уривок. За неоднозначності вибирається книга; якщо аудіо відсутнє — повідомлення про необхідність підготовки татом. Автоматичний запуск довгої paid-генерації дитиною, автоматичне відтворення без натискання, переклад та OCR не реалізовані цим зрізом. Сам репетитор не отримує вигаданого «прочитаного» тексту; є явний перехід до бібліотеки.

Фоновий документ має CAS lease (270 с), run token, per-call reservation; HMAC self-continuation із часовим вікном 60 с та власним namespace. Немає автоматичного повтору невизначеного paid call. Pause не продовжує читання/генерацію; якщо запит уже оплачений, його вартість враховується при завершенні. Resume/delete чекають завершення попереднього lease; незавершений під час аварії виклик лишає резерв. Ретрай після storage/checkpoint збою перевіряє наявний файл перед новою оплатою. Якщо оплачений файл взагалі не зберігся, ручний повтор може вимагати нового синтезу, що явно враховується бюджетом.

[Редакторська self-review](../pedagogy-reviews/2026-11-11-audiobook-editor.md). Без платних API, змін приватної production-бази та нових підписок у цій сесії. Продакшн-ключі не доступні тут для перевірки реального голосу/Drive; перший розділ оцінюється в приватному preview.


Інтеграція з репетитором: явне «прочитай книгу/розділ/сторінку» у текстовому або голосовому діалозі проходить чинну модерацію, після чого детермінований пошук повертає конкретну кнопку готового аудіо або бібліотеки. Не викликає модель для вигадування продовження; посилання зберігається в messages.meta і перевіряється whitelist. Голосова сесія завершує слухання після короткого повідомлення, щоб мікрофон не захоплював аудіокнигу. Дитина натискає «Слухати книгу»; збережено повернення до уроку. «Наступний розділ» без назви/поточної позиції не вгадується: потрібний вибір у змісті; у плеєрі є наступна готова частина.
