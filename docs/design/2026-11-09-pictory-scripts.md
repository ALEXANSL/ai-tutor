# Сценарій Pictory з готового уроку

Батько обирає урок у «Предмети» → «Сценарій Pictory», тривалість і побажання до подачі → явно запускає платний запит OpenAI → перевіряє сцени → копіює повну інструкцію, лише озвучення або візуальні промпти, завантажує TXT. Сценарій зберігається приватно у lesson_video_scripts у межах сім’ї/предмета/теми; bucket створюється сервером під час першого збереження (private, JSON, 150 KB), існуючі buckets не змінюються. Повернення до збереженого сценарію не запускає ШІ. Нова генерація — явна дія; попередній результат зберігається на екрані при збої.

Кожна сцена має назву, точний український текст озвучення, візуальний промпт, посилання на блоки вихідного уроку. Заборонено вигадувати факти, додавати теми, змінювати числа/дати, генерувати текст/літери/числа/субтитри/логотипи у кадрі. Незмінна заборона додається програмно до кожного візуального промпту. Технічні інструкції не є текстом диктора. Тривалість — орієнтовна, за кількістю слів; голос обирається у Pictory. Промпт не гарантує виконання зовнішнім сервісом: результат потрібно переглянути.

Вхід — повні доступні текстові блоки обраного активного уроку з усіх п’яти імпортованих readers, у їх порядку; signed URLs, дитячі профілі/історії/оцінки та приховані відповіді не передаються. Якщо є лише зображення/запитання або текст завеликий, генерація відмовляє з поясненням; не обрізає урок мовчки. Матеріали і побажання — дані, не системні інструкції.

Окрема бюджетована роль lesson_video_script, початково OpenAI gpt-4.1-mini, без прихованого fallback на Claude. Ціни конфігурації — оцінка для обліку, не фактичний рахунок провайдера. Успішний результат перевіряється Zod і посиланнями на реальні блоки. Parent auth перевіряється на сторінці та кожній дії, source IDs отримуються на сервері з family-scoped теми. Генерація не змінює урок/прогрес, не публікує відео, не викликає Pictory чи Gemini API.

Перевірено: 1850 unit tests; після останнього збереження побажань — 20 focused tests і production build (включає TypeScript). ESLint 0 errors / 8 existing warnings; bundle scan 102 files / 0 leaks. Actual component + production CSS у Chromium: 320/390/768/1440 px, light/dark, експорт TXT, відокремлення озвучення, no-text instruction на кожну сцену, відсутність horizontal overflow, touch targets ≥44 px. Це synthetic browser fixtures з mock action; production OpenAI/Storage операції цим сеансом не запускалися.
