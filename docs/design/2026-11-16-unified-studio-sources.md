# Unified sources in AI Studio

The parent can add a local PDF, EPUB, DOCX, PPTX, TXT/MD, PNG or JPEG in the lesson form or Studio materials tab. Upload bytes go directly to the family's Google Drive resumable session; only metadata reaches Vercel. Completion immediately registers and queues the material without a folder scan. The form polls the owned material, shows processing/OCR/errors, and selects the source without discarding its other fields. Creating a lesson remains a separate paid action after successful recognition. Existing Drive/library entry points remain available.

PDF/EPUB retain the existing page/chapter extraction and OCR pipeline. Office/text originals and the uploaded image stay on Drive (large photos are optimized in the browser before upload; the local original is unchanged). Their deterministic extracted units use the existing `manual` indexed-material representation (no new DB format value or required migration); the actual file format is resolved from the stored MIME/name. The worker supports re-extraction of these native uploads while ZIP-manual imports remain protected. Office slide/section units provide locators and deterministic sections and skip the legacy AI textbook-structuring stage. Drive sync must recognize these originals so it cannot mark their indexes removed.

DOCX/PPTX extraction reads bounded OOXML ZIP entries without running macros, external links or embedded code. Preserve paragraphs/tables and presentation order; explain that embedded illustrations, charts and scanned slides are not interpreted by text extraction. Photo recognition uses the existing paid OCR role and family budget with an explicit parent action. Save recognition before downstream writes so retries reuse it; unknown paid failures must not auto-retry. Large scanned PDFs retain the explicit OCR confirmation threshold, available in the same form.

Show real upload progress and processing stage, not an invented percentage for AI work. Retain a completed Drive ID on a confirmation failure so retry does not upload another copy. No originals are made public. Auth, real Drive folder/size checks and family ownership apply on every endpoint. Existing lessons, progress and Drive files are preserved.

Verification: generated PDF/EPUB/OOXML/text fixtures; ZIP/resource/type guards; upload confirmation and idempotency; sync preservation; owned status endpoint; paused OCR; form state and selected material; responsive browser flow. Real Drive/OCR access depends on production credentials and is not simulated as a successful live integration.
