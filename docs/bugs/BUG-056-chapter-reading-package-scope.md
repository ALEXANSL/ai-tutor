# BUG-056 — уривки та біографії можуть змішуватися між курсами

Виявлено 2026-11-09 при підключенні джерела сценарію Pictory.

`getLiteratureV3LessonView` фільтрував reading/biography keys лише в межах сім’ї. `R001`/`B001` можуть повторюватися в різних пакетах; Map за ключем вибирав останній рядок, включно з чужим курсом цієї ж сім’ї. Це стосувалося спільного читача, голосового контексту та нового генератора сценарію.

Регресійний тест відтворив проблему на двох пакетах: до виправлення обрано `other-reading/other-biography`, після — `own-reading/own-biography`. Біографії фільтруються за їх package_id; уривки — через FK work_id до `literature_v3_works!inner(package_id)` (таблиця reading_items власної package_id не має). Дані, IDs, прогрес і файли не змінюються.

Це підтверджена code-level регресія, не доказ того, що конкретні production-уроки вже були змішані. Live private rows у цьому середовищі не читалися.
