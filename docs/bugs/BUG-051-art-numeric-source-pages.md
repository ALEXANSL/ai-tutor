# BUG-051 — пакет мистецтва не проходить перевірку source_pages

2026-10-26, відтворено на наданому PO `JSONS.zip` (163007 bytes). Початковий повний архів не передано в середовище через ліміт інструмента 32 MiB; медіа цього курсу не перевірялися. Вкладення використовуються як дані, жодні інструкції з пакета не виконуються.

## Причина

70 уроків, 142 завдання. У `lessons[].source_pages` знаходяться 242 друковані номери-числа (наприклад `[4,4,6]`), а контракт вимагає рядкових ID сторінок каталогу. Каталог містить 204 сторінки й однозначні відповідності для всіх цих номерів. Строга перевірка відхиляла весь course.json; далі з’являлися похідні повідомлення про відсутні задачі для приватних ключів. Виправлення діагностики PR121 показує точні JSON-шляхи, але саме по собі не змінює пакет.

## Виправлення

У єдиному ZIP-імпортері перед строгою перевіркою лише для `lessons[].source_pages` узгоджуємо додатні безпечні цілі номери з `catalog/pages.json.printed_page` й беремо фактичний `id`. Наявні рядкові ID, порядок і повтори залишаються; інші поля, числові значення контенту, тести, назви та медіа не змінюються. Загальне перетворення number → string не застосовується: рядок `"4"` не є правильним ID, якщо в каталозі його немає.

Якщо відповідності немає або номер відповідає кільком різним ID, імпорт блокується з точним шляхом і вимогою явного ID. Не вигадуємо назви за префіксом книги та не плутаємо друкований номер з позицією у PDF. Перевірки версій, book_id, приватних ключів, flow та ізоляція сім’ї залишаються.

Універсальний промпт уже уточнений у PR121: нові пакети повинні одразу використовувати ID, це сумісність для існуючих підготовлених архівів. Після деплою початковий ZIP можна повторно перевірити в тій самій формі; fingerprint перевіряється за вихідними байтами, файл не переписується.

## Перевірки

- Повторна перевірка реальних JSON: 70 уроків, 142 завдання, 0 помилок. Попередження про відсутні PDF/зображення очікувані для JSONS.zip; оцінити повний набір медіа за ним неможливо.
- Синтетичні тести: змішані ID/числа, збереження повторів/числового grade; друкований номер відрізняється від source_pdf_page; невідомий, нульовий, від’ємний, дробовий, небезпечний цілий і неоднозначний номери блокуються.
- 1786 unit-тестів, TypeScript і production build пройдені. Lint: 0 помилок, 8 наявних попереджень; bundle scan: 100 файлів, 0 витоків за маркерами. Після зміни обмежень середовища повторну збірку й тести виконано з дозволеним запуском дочірніх процесів: sandbox повертав EPERM/порожній stdout для child_process, що відтворено окремою нешкідливою Node-пробою.
