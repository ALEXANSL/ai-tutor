# Відео як додатковий матеріал: аудит 2026-10-23

Вимога PO: вже додані Pictory-відео з історії (§16, §17, §18–19) мають відкриватися в modal; наявні текстові уроки, порядок кроків і прогрес зберігаються.

## Підтверджені кодом дефекти

- Child subject показує відео лише всередині відфільтрованих topics. Після імпорту старі topics приховані. PR112 звузив новий вибір тем, але не відновив доступ до відео на вже прихованих topics.
- Відеокнопки взагалі немає всередині сторінок імпортованих уроків.
- Плеєр не обробляє exception server action і native media error: можливе нескінченне «завантаження». Немає захисту від запізнілого URL після close/reopen, Escape/focus trap, взаємного виключення з озвученням.
- Backend перетворює SQL/signing error на порожній список або «немає відео», маскуючи причину. Upload complete довіряє клієнтським MIME/розміру й не перевіряє наявність об’єкта.

## Виправлення

Незалежний блок усіх відеоматеріалів предмета (включно зі старими прив’язками), без повторного upload/переміщення тем. Додаткова кнопка в наявному уроці: точна прив’язка topic_id; для старих topics допускається лише унікальний точний збіг нормалізованої назви в межах того самого предмета. За неоднозначності відео залишається доступним у списку предмета, без вгадування за числами. Медіапомилки мають retry; modal зупиняє озвучення й відкидає запізнілі відповіді, закриття/навігація зупиняють відео. Відео не стає обов’язковим кроком уроку.

Збої додаткового відеокаталогу не блокують текстові уроки. Доступ до файлів — лише сім’я поточної дитини і видимий предмет/курс. Існуючі записи, файли та lesson data не переписуються.

## Межі аудиту

У середовищі немає service-role ключа production і callable Supabase/Vercel management API. Вміст трьох production записів та кодек їхніх файлів не прочитано. Доступність реального MP4 підтверджується лише авторизованим переглядом; локальні тести використовують синтетичні дані й відео.
