# BUG-059 — доопрацювання в Майстерні не показувало зрозумілий прогрес

2026-11-11. Власник після «Доопрацювати» не бачив підтвердження/спіннера; стара рецензія залишалася в довгому відкритому preview, керування було нагорі за межами екрана. Повторна рецензія підтвердила завершення попередньої роботи: не стверджуємо зупинку провайдера чи черги без live журналів.

Виправлення: компактна sticky панель стану й дій, миттєве підтвердження надсилання/прийняття, етапи автор → схеми → рецензія без вигаданих відсотків, фактичний queued/running/activeCall з parent-only polling, явне останнє оновлення/помилка зв’язку, ручний refresh, пауза та повтор після збою. Після запуску фокус/скрол переходить до стану, попередній матеріал позначається попередньою версією. Зауваження рецензента вже додаються сервером: UI пояснює, що копіювати їх не потрібно, й дозволяє доопрацювання без ручного тексту. Публікація після позитивної рецензії доступна також нагорі, місце появи курсу пояснено, новий курс веде в /parent/courses/[id].

Не змінює критерії рецензії, бюджет, провайдера, чернетки, матеріали або правила публікації. Новий статус черги не містить ключів, тексту промптів чи чужих даних. Приватний стан конкретного production-проєкту у цій сесії не читався. Без платних AI-викликів.
