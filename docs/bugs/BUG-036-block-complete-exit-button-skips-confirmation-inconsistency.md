# BUG-036 — «Вийти з уроку» на екрані «Блок завершено!» пропускає підтвердження, на відміну від однойменної кнопки деінде в уроці

| Поле | Значення |
|---|---|
| Статус | Open (non-blocking, знайдено QA під час перевірки BUG-034) |
| Серйозність | Minor — UI-неузгодженість, не функціональна поломка |
| Пов'язано з | `app/src/components/lesson/LessonRunner.tsx` |

## Опис
У межах фіксу BUG-034 QA незалежно перевірив код і виявив: нова кнопка «Вийти з уроку» на `BlockCompleteScreen` (рядки ~961-967) викликає `exitLesson()` напряму, без підтвердження. Але та сама підпис-мітка «Вийти з уроку» деінде в цьому ж файлі (рядки ~530-536, 565-578) відкриває діалог підтвердження («Вийти з уроку?» / «Так, вийти» / «Ні, продовжити урок») перед викликом `exitLesson()`.

Вимога «без підтвердження» в `docs/01-requirements.md` (НФВ-PERF-6/КП-3) стосується окремої кнопки «🏠 На головну» (`navHome`), а не «Вийти з уроку» — тобто нова кнопка на `BlockCompleteScreen` технічно коректно уникає підтвердження (відповідає духу BUG-034 — «завжди можна вийти без перешкод»), але має **той самий видимий напис**, що й кнопка з підтвердженням в іншому місці того ж екрана уроку — дитина/тато можуть очікувати однакову поведінку від однакового напису.

## Завдання для developer (не терміново)
Або (а) дати кнопці на `BlockCompleteScreen` окремий напис/фрейминг (ближче до `navHome` — «На головну» замість «Вийти з уроку»), або (б) явно задокументувати навмисну відмінність поведінки для цього конкретного напису на цьому конкретному екрані. Не блокує реліз BUG-034/BUG-035.
