# Географія: PDF/ілюстрації та озвучення після переходу

Запит власника: після імпорту географії немає частини ілюстрацій і не відкриваються сторінки підручника; озвучення продовжується після виходу з уроку або переходу далі. Уточнення: PDF можуть надходити окремим ZIP папки `lessons`.

Причини:
- Імпортер розглядав лише ZIP-шляхи `assets/`, хоча наданий каталог містить `lesson_pdfs/L001.pdf` та ще 58 PDF. Повні архіви також можуть мати зовнішню папку.
- Три додаткові ілюстрації мають `kind: workbook_illustration` і `page_id: null`; старий парсер відкидав їх.
- Повторний імпорт без бінарних файлів обнуляв `storage_path` вже завантажених матеріалів.
- Озвучення, запитане до переходу, могло завершити генерацію пізніше й запуститися після зникнення компонента; звичайні HTML audio також потребували зупинки при демонтуванні.

Очікувана поведінка та виправлення:
- Сім JSON залишаються каталогом/текстом. Два необов'язкові поля ZIP: ілюстрації або повний пакет; окремі PDF-уроки (`lessons`/`lesson_pdfs`, також вміст папки без обгортки). Шляхи зіставляються з каталогом; неоднозначні назви відхиляються.
- Збережені файли переживають імпорт лише JSON та невдалу заміну. Нові бінарні файли записуються за шляхом із хешем вмісту. Змінені описи без заміни файлу спричиняють попередження.
- Покажчик підручника пропонує лише PDF із завантаженим файлом і використовує номер сторінки всередині PDF уроку.
- Кожне активне або очікуване озвучення має власника; зміна матеріалу, вихід із компонента або навігація скасовують його. Запізніла відповідь не запускає голос. Скасування не перемикає урок як природне завершення аудіо.

Перевірка наданих семи JSON після виправлення парсера: 59 уроків, 590 завдань/ключів, 270 посилань на файли, 241 сторінка; 0 помилок і попереджень. Серед файлів — 59 PDF; за наявності всіх PDF покажчик містить 231 сторінку. Справжні PDF/зображення в цих JSON відсутні; необхідний повторний імпорт архівів у батьківському кабінеті. Приватний вміст підручника та ключі відповідей у репозиторій не додавалися.

Міграції БД і платні виклики ШІ для виправлення не потрібні. Автоматичні перевірки покривають структуру ZIP, збереження файлів при повторному імпорті, номери сторінок PDF та активне/запізніле озвучення під час переходів.
