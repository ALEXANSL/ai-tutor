# Сортування вже імпортованих параграфів без повторного ZIP

PO 2026-10-26: уроки історії невпорядковані, потрібний параграф доводиться шукати. Попередня зміна `literatureV3Persist.leadingParagraphNumber` виправляла sort_order лише при наступному import/upsert; збережені topics не оновлювалися, package TOC узагалі читав старий order_no.

Рішення: одна read-time функція природного сортування явних префіксів § N / Параграф N. Вона застосовується до V3 topics у subject read model, package list для TOC/prev/next і дитячого списку відеоматеріалів. Параграфи 2, 9, 10, 18–19, 20 йдуть за числовим порядком. Незанумеровані вступи/підсумки зберігають свої позиції; однакові номери — свій попередній взаємний порядок. Числа в середині назв (дати, номери задач) не є ключем. Для інших систем імпорту порядок topics не змінюється. У V3 змісті показується послідовний ordinal поточного відсортованого списку.

Жодних DB writes, міграції, повторного import чи зміни IDs, lesson flow, PDF, illustrations, відеоприв’язок або прогресу. Авторизований production список недоступний у runtime; перевірка на synthetic rows і production build, фактичні підписи збережених уроків перевіряються користувачем після публікації.
