# План розвитку персонального репетитора

Дата: 2026-10-21. Статус: вимоги й пропозиція реалізації; **функції нижче ще не реалізовані цим документом**. Зріз коду: `54de85e5647ec9fb89c492ff6d238a32fce641a4`.

Мета Алекса — цікавий і уважний репетитор для власної дитини, який допомагає навчатися з планшета під час перерв у шкільному навчанні в Києві. Голосовий діалог уже працює. Наступний крок — зробити його обізнаним про урок, корисним поза підручником і здатним поступово враховувати побажання дитини. Комерційна платформа й навчання власної моделі зараз не є умовою успіху.

## Що пропонуємо робити

1. **Репетитор знає урок.** Дати йому перелік усіх блоків і задач, знаходити №357 за друкованим номером, пояснювати потрібне завдання й повертатися до місця зупинки.
2. **Живий навчальний діалог.** Новий маніфест: пояснення відповідно до віку, короткі жарти й відступи, цікаві факти поза підручником, чесне розрізнення знання й припущення. Для актуальної чи непевної інформації — перевірені джерела.
3. **Один архів для імпорту.** Вибрати предмет і готовий ZIP. Платформа визначає підтримуваний формат, знаходить JSON, `assets/` і `lessons/`, показує результат перевірки й імпортує. Медіа необов’язкові; старі формати читають наявні адаптери.
4. **Керована пам’ять.** Спочатку явні побажання («мені цікава астрономія»), потім обережні спостереження про навчання з доказами. Дитина й тато бачать, виправляють і видаляють пам’ять.
5. **Спільна команда розробки.** Codex, Claude Code у браузері та Gemini працюють зі спільними задачами GitHub. Один виконавець, незалежний рецензент, один інтегратор; результати підтверджуються кодом і перевірками.

Пункти 1–3 можна розробляти окремими невеликими змінами; пам’ять не повинна затримувати виправлення задач і голосового діалогу. Наявне розміщення ілюстрацій у кінці уроків не змінюємо.

## Що вже встановлено, а що потребує перевірки

У коді є пошук задач за `original_number`, пошук матеріалів, голосовий цикл і сімейний бюджет — використовуємо їх. Довгостроковий профіль описаний у старих вимогах, але не реалізований як керована пам’ять. Інструкція «лише матеріали підручника» суперечить новому запиту власника.

Claude працює у Алекса на `claude.ai`. Офіційна документація описує передавання завдання в наявну хмарну сесію через CLI, але CLI, авторизація тієї ж обліковки та прив’язка сесії в цьому виконавчому середовищі ще не перевірені. Наявність API-доступів сама по собі цього не забезпечує. Gemini пропонується спочатку як внутрішній рецензент коду для дорослої команди, без дитячих даних.

Цей пакет містить документацію й шаблони контрактів. Він не запускає платні моделі, не змінює БД, не підключає зовнішні сесії та не розгортає нову версію застосунку.
