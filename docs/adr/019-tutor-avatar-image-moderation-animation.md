# ADR-019. Аватар репетитора: картинка в приватному сховищі без модерації в MVP, анімація на клієнті; говорящий аватар — точка розширення

- **Статус:** запропоновано (2026-09-25); **оновлено 2026-09-25 за рішенням PO: автоматична модерація аватара в MVP не потрібна** (один користувач, дитина 11 років; тато бачить кожну зміну)
- **Вимоги:** D-45, D-46, US-1.8, NFR-SAFE-1, NFR-SAFE-14, NFR-PRIV-5, NFR-PRIV-12, NFR-A11Y-7, NFR-PLAT-4, R-22, R-23, ВП-33

## Контекст
Дитина обирає аватар репетитора: готовий («вогник» — за замовчуванням) або власну картинку. Картинка не повинна потрапляти до жодних моделей чи сторонніх сервісів; EXIF — видаляти; тато бачить і може замінити. У MVP — проста анімація за станами голосу без витрат; «говорящий» аватар з рухом губ — Фаза 2.

Рішення PO 2026-09-25: у застосунку один користувач-дитина; автоматична модерація (MediaPipe на пристрої, OpenAI `omni-moderation`, Google Cloud Vision SafeSearch) у MVP — зайва складність і зайвий шлях передачі дитячого зображення назовні. Контроль — тато.

## Рішення
1. **Зберігання:** готові аватари — статичні файли застосунку; власні — приватний бакет Supabase `tutor-avatars`, шлях `{family_id}/{avatar_id}.webp`, підписані посилання ≤ 10 хв, останні 5 завантажень; таблиця `tutor_avatars` (`status`: `active` / `replaced_by_parent` / `archived`).
2. **Валідація формату й розміру:** JPEG/PNG/WebP (HEIC — якщо браузер декодує), до 10 МБ на вході; **SVG і GIF заборонені**. На пристрої — кроп до квадрата, **512 × 512, WebP ~80 % (≤ ~150 КБ), без EXIF**; на сервері — перевірка сигнатури файлу, ≤ 1 МБ, повторне перекодування `sharp` (гарантує відсутність EXIF і прихованого вмісту).
3. **Жодних передач назовні:** зображення **не передається жодним моделям і стороннім сервісам** (ні розмовним, ні класифікаторам). Автоматичної модерації в MVP немає.
4. **Тато:** кожна зміна аватара — подія в центрі сповіщень з мініатюрою (не термінова); у кабінеті «Образ репетитора» — «Замінити» (готовий або свій файл, ті самі обмеження), «Скинути на вогник», перемикач `persona_child_editable` (дитина може / не може змінювати аватар, голос, ім'я).
5. **Анімація MVP:** `TutorPresenter` → `AnimatedImagePresenter`: CSS transform/opacity + легкий Canvas; стани `idle` / `listening` / `thinking` / `speaking` / `paused`, рівень гучності з ElevenLabs SDK або `AnalyserNode` для кешованої озвучки; ≤ 30 кадрів/с; `prefers-reduced-motion` і перемикач «Менше руху». $0.
6. **Точка розширення (модерація):** серверний маршрут `persona` має місце для необов'язкового кроку `AvatarCheck` (інтерфейс, у MVP — no-op); при комерціалізації підключається модерація зображень — ADR-018. Колонка `tutor_avatars.moderation_status` не створюється зараз; додається міграцією разом із модерацією.
7. **Точка розширення (Фаза 2, говорящий аватар):** шина `SpeechBus` (стан, гучність, опц. таймінги символів); `audio_assets.alignment` з TTS «with timestamps»; нові реалізації `RigPresenter` (персонаж на клієнті) або `StreamingAvatarPresenter` (хмарний рендер) + серверний `AvatarProvider`, тип витрат `avatar`, роль `avatar_render`; `tutor_avatars.kind` розширюється. Оркестратор, client tools, транскрипти, модерація текстів і бюджет не змінюються.

## Альтернативи
| Варіант | Ціна | Чому не обрано |
|---|---|---|
| Автоматична модерація: MediaPipe (обличчя на пристрої) + `omni-moderation` + резерв Cloud Vision SafeSearch (попередня версія ADR) | $0 | Рішення PO: для одного користувача зайва складність (+≈0,5–1 день), додатковий Google API і передача дитячого зображення стороннім сервісам. Перенесено в «при комерціалізації» (ADR-018) |
| Модерація через vision-LLM | ≈ $0,001 за зображення | Розмовна модель — суперечить US-1.8 / NFR-PRIV-12 |
| Ручне затвердження татом до показу | $0 | Дитина чекає; достатньо, що тато бачить подію й може замінити/скинути |
| Зберігати аватар у бакеті `child-media` | — | Той бакет очищується після щомісячного архіву; активний аватар не повинен зникати |
| Говорящий аватар одразу в MVP | ≈ $6–210/міс на «Економі» (`docs/03` 3.9) | Рішення PO: Фаза 2, окреме рішення про вартість і приватність |

## Наслідки
- MVP: $0/міс; ≈ 1 день розробника (кропер і стиснення, серверна перевірка, кабінет тата, анімація) — на ≈ 0,5–1 день менше, ніж з модерацією.
- Cloud Vision API не вмикається; у чеклисті Алекса кроку немає.
- Прийнятий ризик: недоречна картинка може з'явитися до того, як тато її побачить (AR-R17) — зображення бачить лише сама дитина, тато отримує подію й може скинути аватар.
- Ризик: продуктивність анімації на Lenovo Yoga 11 разом з WebRTC (AR-R19).
- Для Фази 2 з хмарним рендером картинка потрапить до стороннього постачальника — потрібне окреме рішення щодо приватності; клієнтський персонаж (клас A) цього уникає.
- Деталі — `docs/02-architecture.md`, 7.6.4–7.6.5; вартість — `docs/03-resources-and-costs.md`, 3.9.
