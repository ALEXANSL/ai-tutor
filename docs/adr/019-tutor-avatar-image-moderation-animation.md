# ADR-019. Аватар репетитора: картинка в приватному сховищі, модерація без розмовних моделей, анімація на клієнті; говорящий аватар — точка розширення

- **Статус:** запропоновано (2026-09-25)
- **Вимоги:** D-45, D-46, US-1.8, NFR-SAFE-1, NFR-SAFE-14, NFR-PRIV-5, NFR-PRIV-12, NFR-A11Y-7, NFR-PLAT-4, R-22, R-23, ВП-33

## Контекст
Дитина обирає аватар репетитора: готовий («вогник» — за замовчуванням) або власну картинку. Картинка не повинна потрапляти до розмовних моделей; EXIF — видаляти; потрібна автоматична перевірка на недоречний вміст і підказка «не фото реальних людей»; тато бачить і може замінити. У MVP — проста анімація за станами голосу без витрат; «говорящий» аватар з рухом губ — Фаза 2.

## Рішення
1. **Зберігання:** готові аватари — статичні файли застосунку; власні — приватний бакет Supabase `tutor-avatars`, шлях `{family_id}/{avatar_id}.webp`, підписані посилання ≤ 10 хв, останні 5 завантажень; таблиця `tutor_avatars` зі статусом модерації.
2. **Обмеження й стиснення:** JPEG/PNG/WebP (HEIC — якщо декодується), до 10 МБ на вході; SVG і GIF заборонені. На пристрої — квадрат 512 × 512, WebP ~80 % (≤ ~150 КБ), без EXIF; на сервері — перевірка сигнатури, ≤ 1 МБ, повторне перекодування `sharp`.
3. **Перевірка (ВП-33 — без розмовних моделей):**
   - шар 0, на пристрої: MediaPipe Face Detector → реалістичне обличчя → підказка; якщо все ж завантажено → `pending_parent`;
   - шар 1, сервер: **OpenAI `omni-moderation-latest`** (спеціалізований класифікатор, безкоштовно, приймає зображення);
   - резерв: **Google Cloud Vision SafeSearch** (1 000/міс безкоштовно, далі $1,50 / 1 000); обидва недоступні → `pending_parent`;
   - результати: `approved` / `pending_parent` / `rejected` (карантин 30 днів, видно лише татові); тяжкі категорії → `safety_events` `urgent`.
4. **Тато:** бачить кожну зміну (подія з мініатюрою), затверджує `pending_parent`, замінює/скидає аватар, може заборонити дитині змінювати аватар, голос чи ім'я (`persona_child_editable`).
5. **Анімація MVP:** `TutorPresenter` → `AnimatedImagePresenter`: CSS transform/opacity + легкий Canvas; стани `idle` / `listening` / `thinking` / `speaking` / `paused`, рівень гучності з ElevenLabs SDK або `AnalyserNode` для кешованої озвучки; ≤ 30 кадрів/с; `prefers-reduced-motion` і перемикач «Менше руху». $0.
6. **Точка розширення (Фаза 2):** шина `SpeechBus` (стан, гучність, опц. таймінги символів); `audio_assets.alignment` з TTS «with timestamps»; нові реалізації `RigPresenter` (персонаж на клієнті) або `StreamingAvatarPresenter` (хмарний рендер) + серверний `AvatarProvider`, тип витрат `avatar`, роль `avatar_render`; `tutor_avatars.kind` розширюється. Оркестратор, client tools, транскрипти, модерація й бюджет не змінюються.

## Альтернативи
| Варіант | Ціна | Чому не обрано |
|---|---|---|
| Модерація через vision-LLM (Claude Haiku 4.5 / Gemini Flash) з дитячою рубрикою | ≈ $0,001 за зображення | Точніше для «страшних» картинок, але це розмовна модель — суперечить US-1.8 / NFR-PRIV-12. Можна ввімкнути лише за окремим рішенням Алекса |
| Лише Cloud Vision SafeSearch | $0 у межах 1 000/міс | Лишаємо резервом: ще один провайдер у критичному шляху без виграшу над безкоштовним `omni-moderation` |
| AWS Rekognition та подібні | центи за 1 000 | Новий акаунт і ключі — зайва складність |
| Лише ручне затвердження татом кожної картинки | $0 | Дитина чекає; тато все одно бачить кожну зміну — автоматика + `pending_parent` при сумніві достатні |
| Зберігати аватар у бакеті `child-media` | — | Той бакет очищується після щомісячного архіву; активний аватар не повинен зникати |
| Говорящий аватар одразу в MVP | ≈ $6–210/міс на «Економі» (класи B–C, `docs/03` 3.9) | Рішення PO: Фаза 2, окреме рішення про вартість і приватність |

## Наслідки
- MVP: ≈ $0/міс; ≈ 1–2 дні розробника (кропер, перевірки, кабінет, анімація).
- Ризики: пропуски / хибні спрацювання модерації (AR-R17); продуктивність анімації на Lenovo Yoga 11 разом з WebRTC (AR-R19).
- Для Фази 2 з хмарним рендером картинка потрапить до стороннього постачальника — потрібне окреме рішення щодо приватності; клієнтський персонаж (клас A) цього уникає.
- Деталі — `docs/02-architecture.md`, 7.6.4–7.6.5; вартість — `docs/03-resources-and-costs.md`, 3.9.
