# ADR-003. Доступ до Google Drive: сервісний акаунт для матеріалів + OAuth `drive.file` для архіву

- **Статус:** запропоновано (2026-09-25)
- **Вимоги:** AR-3, US-2.1, US-18.1 КП-2, NFR-PRIV-7, 8, R-8, D-24

## Контекст
Підручники лежать у папці особистого «Мій диск» Алекса (зараз відкрита за посиланням). Застосунок має: читати файли папки матеріалів; щомісяця **записувати** архів у приватну папку; перевіряти, чи папки не відкриті за посиланням. ID папок — лише в змінних середовища.

Обмеження Google (перевірено 2026-09-25):
- сервісні акаунти **не мають квоти сховища** і не можуть створювати файли в особистому «Мій диск» (спільні диски — лише Google Workspace);
- у статусі OAuth «Testing» refresh-токени спливають через **7 днів**;
- `drive.file` — **не чутливий** скоуп (перевірка Google не потрібна); `drive` / `drive.readonly` — обмежені (restricted), потребують перевірки для «In production».

## Рішення
- **Читання матеріалів — сервісний акаунт** з роллю «Читач» на папці `GOOGLE_DRIVE_FOLDER_ID`. Ключ — `GOOGLE_SERVICE_ACCOUNT_JSON`.
- **Запис архіву — OAuth тата зі скоупом `drive.file`**, застосунок у статусі «In production». Тато один раз натискає «Підключити архів» → застосунок **сам створює** приватну папку архіву (файли належать Алексу) → ID вноситься в `GOOGLE_DRIVE_ARCHIVE_FOLDER_ID`. Refresh-токен — у Supabase Vault.
- **Перевірка публічності:** папка матеріалів — анонімний запит метаданих з `GOOGLE_API_KEY` (успіх = відкрита за посиланням) → попередження; папка архіву — перелік дозволів токеном власника, будь-який `anyone` → архівація блокується.

## Альтернативи
| Варіант | Чому ні |
|---|---|
| Лише сервісний акаунт | Не може записати архів (немає квоти) |
| Лише OAuth `drive` / `drive.readonly` | Обмежені скоупи → перевірка Google або 7-денні токени в «Testing» |
| Лише OAuth `drive.file` + Google Picker для кожного підручника | Кожен новий PDF треба вручну «вибирати» в застосунку — незручно для тата |
| Режим «Testing» | Архів 1-го числа падав би через протухлий токен |

## Наслідки
- Два механізми, але кожен простий і не спливає.
- Архів займає місце в Drive Алекса (≈ 0,5 ГБ/міс) — перевірка вільного місця перед архівацією.
- **Припущення (перевірити на S1):** анонімний запит з API-ключем повертає метадані папки «за посиланням». Запасний спосіб — роль «Редактор» для сервісного акаунта лише для читання дозволів.
