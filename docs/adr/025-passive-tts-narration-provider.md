# ADR-025. Пасивна озвучка (не жива розмова): OpenAI/Gemini TTS для «почитай мені параграф»

- **Статус:** запропоновано (2026-09-27) — рішення (запускати функцію в MVP чи ні, і який провайдер саме) за PO
- **Вимоги:** запит PO 2026-09-27 («пошук наявних TTS-можливостей у вже підключених ШІ»); пов'язана майбутня US про читання параграфа/розділу (додає `product-manager` паралельно); NFR-VOICE-1 (єдиний образ репетитора), NFR-PRIV-1 (умови «не навчати на даних»)

## Контекст

PO попросив перевірити, чи можна заощадити на озвучці, використовуючи вже підключені провайдери (OpenAI, Google Gemini) замість ElevenLabs (свідомо відкладеного, розд. 7.4 `docs/02`) — конкретно для нової можливості «почитай мені параграф» / читання розділу як аудіокниги (гуманітарні предмети, розд. 5.5 `docs/02`). Це **не** стосується живого голосового діалогу (ADR-006) — лише одноразової озвучки вже готового тексту.

## Рішення

1. Додається нова роль маршрутизатора **`passive_narration`** (окрема від `tts` — образу репетитора, розд. 7.3/7.6 `docs/02`), яка озвучує **вже готовий, не персонований** текст (параграф з підручника/художнього твору) — не потребує узгодженості з голосом, обраним дитиною для репетитора.
2. Основний провайдер — **OpenAI `gpt-4o-mini-tts`** (керованість тону — «читай тепло й спокійно, як аудіокнига»; ключ уже є); запасний/альтернативний кандидат — **Google `gemini-3.8-flash-tts`** (офіційно підтверджена українська). Обидва ≈ у 3–7 разів дешевші за ElevenLabs для цього застосування.
3. Кешується тим самим механізмом `audio_assets` (розд. 8.2 `docs/02`) з новою колонкою **`audio_assets.provider`** (`elevenlabs`/`openai`/`gemini`).
4. Ця функція **не залежить** від рішення по ADR-006 (жива розмова) і може розроблятися незалежно/раніше — вона на порядок простіша (немає Agents/WebRTC/client tools, лише «текст → аудіофайл → кеш → плеєр»).
5. Голос диктора **не** буде голосом репетитора (інший провайдер) — в інтерфейсі підписується окремо («Читає диктор»), щоб не порушити NFR-VOICE-1 (ця вимога стосується образу репетитора, не начитки оригінального тексту книги).

## Альтернативи

| Варіант | Чому ні (або чому пізніше) |
|---|---|
| ElevenLabs TTS (без Agents) для цієї ж функції | У 3–7 разів дорожче; можливий пізніше, якщо PO забажає той самий голос репетитора й для читання розділів — тоді ADR переглядається |
| Чекати на ElevenLabs (S12) і не робити нічого раніше | Функція проста й дешева — немає причин чекати на живий голос, який відкладено з інших причин |
| tts-1 (простіший, без керованості тону) | Запасний варіант, якщо `gpt-4o-mini-tts` виявиться гіршим на слух або дорожчим на практиці |

## Наслідки

- Нова роль у `model_routes`, нова колонка `audio_assets.provider`; без нових акаунтів/ключів.
- Оцінка вартості — `docs/03-resources-and-costs.md` розд. 2.2.2 (≈ $1–3/міс додатково при регулярному використанні).
- **Відкрите питання до PO:** запускати цю функцію в MVP зараз, чи після ElevenLabs (єдиний голос для всього)? Чи прийнятний окремий голос диктора, відмінний від голосу репетитора?
