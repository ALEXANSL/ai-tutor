# ADR-014. Бібліотека уроків: версіоновані пакети кроків з озвучкою, без даних дитини

- **Статус:** запропоновано (2026-09-25)
- **Вимоги:** AR-16, E-19 (US-19.1…19.4), US-13.4, NFR-COST-11, P-R, D-34, PM-15

## Контекст
Кожен згенерований урок зберігається й проходиться повторно без генерації; повторення беруть збережені вправи; альтернативні пояснення перевикористовуються; «Перегенерувати» створює версію; бібліотека архівується, але ніколи не видаляється; основа для офлайну R2.

## Рішення
- **Модель:** `library_items` (блок / набір повторення / банк діагностики / альтернативне пояснення; тема; версія; статус `active`/`superseded`; тег інтересу; модель і версія промпту; джерела) → `library_steps` (тип кроку, `content jsonb`: слайд, питання, еталон, рубрика, розгалуження, альтернативи; `visual jsonb`; `source_refs`) → `audio_assets` (озвучка, `text_hash`, `voice_id`).
- **Без ПД:** нікнейм — плейсхолдер `{{nickname}}` лише в тексті, підставляється при показі; в аудіо звертання немає.
- **Генерація один раз:** оркестратор спершу шукає активний блок теми (з урахуванням тегу інтересу); якщо немає — `lesson_generation` → валідація JSON-схеми (кожен факт з посиланням на сторінку) → збереження → задача озвучки.
- **Повторення (PM-15):** зі збережених вправ; нові генеруються лише якщо вправи теми використано в останніх 2 повтореннях або їх бракує — і теж зберігаються.
- **Версії:** «Перегенерувати» з коментарем тата → нова версія `active`, стара — `superseded` з позначкою «замінено татом»; прогрес дитини прив'язаний до теми й спроб, не губиться.
- **Показник економії:** частка повторних проходжень без генерації — з `ai_calls` і `session_blocks`.
- **Архів:** копія створеного/зміненого за місяць — у щомісячний архів (ADR-013), без видалення.

## Альтернативи
| Варіант | Чому ні |
|---|---|
| Генерувати урок щоразу | Дорожче в рази й нестабільний зміст (P-R) |
| Зберігати урок як один документ/HTML | Не можна перевикористати окремі кроки, альтернативи й вправи; складніше офлайн |

## Наслідки
- Обсяг: ≈ 4,6 МБ озвучки на 30-хв урок; ≈ 0,5–1,5 ГБ за навчальний рік.
- R2 (офлайн): пакет = JSON кроків + аудіо — завантажується на планшет без зміни схеми.

## Примітка (2026-09-26, D-55): педагогічний конвеєр і статуси
Наповнення бібліотеки (крок «якщо немає — `lesson_generation`») замінюється конвеєром **планування → генерація → незалежна рецензія іншим провайдером → (≤ 2 доопрацювання)** — ADR-022. `library_items.status` розширено: `draft`/`active`/`needs_review`/`superseded`; оркестратор для показу дитині бере лише `active`. Додано `pedagogy jsonb` (методичний паспорт: мета, міскончепції, прийоми, «гачок», результат рецензії) і `child_feedback jsonb`; нова таблиця `library_item_reviews` — історія рецензій. «Перегенерувати» (версії, вище) запускає той самий конвеєр заново, а не лише `lesson_generation`. Деталі — ADR-022, `docs/02-architecture.md` розд. 7.7, 8.2.
