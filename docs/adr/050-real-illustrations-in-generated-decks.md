# ADR-050. Справжні ілюстрації в озвучених презентаціях замість абстрактних фігур

- **Статус:** прийнято (2026-11-27, рішення PO D-139)
- **Пов'язані:** ADR-048 (презентація з уроку), ADR-049 (ElevenLabs і відео), скіл `lesson-visual-style`, `docs/03-resources-and-costs.md` розд. «Ілюстрації презентацій»

## Контекст
Алекс показав останній слайд уроку «Давня Греція»: замість ілюстрації — трикутники й прямокутники. Причина: конвеєр презентацій (`server/decks/workflow.ts`) не викликав генератор зображень. Він шукав фото у Wikimedia Commons за `photoQuery`, а якщо фото не знаходилось (чи модель лишала запит порожнім для «схем»), просив текстову модель «намалювати» слайд 5–12 примітивами pptx. Генерація зображень (`server/studio/image-provider.ts`, Gemini / OpenAI) існувала лише як ручна кнопка в уроках Майстерні.

## Рішення
1. У сценарії кожен слайд отримує `imagePrompt` — конкретну сцену, що пояснює саме думку слайда (не прикрасу); `caption` підказує, на що дивитися. Порожній `imagePrompt` — лише коли картинка введе в оману (точна математика, формула).
2. Новий крок «ілюстрації» (`server/decks/visuals.ts`), по 3 слайди за крок фонової черги: генерація через уже підключений сервіс зображень (спершу Gemini, якщо є ключ, інакше OpenAI; `DECK_IMAGE_PROVIDER` може закріпити), стиль за предметом сцени: пейзажі, природа, пам’ятки й артефакти — фотореалістичне фото; люди й події минулого — реалістичний історичний живопис (еталон Алекса 2026-11-27: аерофото Егейського моря з островами), без тексту на картинці, історична/наукова точність, безпечно для дитини.
3. Запасний варіант — фото з вільною ліцензією з Commons; якщо й його немає — слайд лише з текстом на всю ширину. Абстрактні фігури більше не малюються.
4. Кеш: картинка зберігається приватно в `course_assets/deck-images/{family}/{sha256(провайдер+модель+промпт)}.jpg`; повторна збірка не платить удруге.
5. Кожен виклик пишеться в облік ШІ (роль `deck.illustration`) з фактичною або обережною ціною; над сімейним лімітом генерація не запускається; можливо оплачений збій не повторюється автоматично.
6. Кнопка «Перемалювати ілюстрації» на сторінці готової презентації: сценарій і текст озвучки лишаються, тому збережені аудіо перевикористовуються; платяться лише нові картинки (оцінка показана біля кнопки). Для старих презентацій без `imagePrompt` один виклик текстової моделі дописує сцени.

## Наслідки
- Вартість: ≈ $0,04 за картинку (Gemini 1K) або ≈ $0,05 (gpt-image-1 medium 1024²), тобто ≈ $0,25–0,50 на урок із 6–12 слайдів. Нових підписок чи сервісів немає.
- Схеми з підписами, карти й таймлайни, де точність важливіша за атмосферу, згенерована картинка не замінює: наступний крок — кодові схеми (SVG) для таких слайдів за `lesson-visual-style` §1.
