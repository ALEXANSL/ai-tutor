# ADR-012. Облік витрат і режим бюджету

- **Статус:** запропоновано (2026-09-25); ліміт $100 лише для ШІ і перші 2 тижні зі щоденним моніторингом — погоджено Алексом 2026-09-25
- **Вимоги:** AR-11, US-11.5 КП-1…КП-10, US-7.2, NFR-COST-1, 2, 4, 8, NFR-SAFE-13, D-27, PM-10

## Контекст
Ліміт на місяць (за замовчуванням $100), пороги 80 / 100 / 110 %, дозавершення поточного уроку, економ-моделі, жорстка межа, безпека понад ліміт, визначення порогу ≤ 1 хв після виклику.

## Рішення
- **Що входить у ліміт (рішення Алекса 2026-09-25):** лише змінні ШІ-витрати. Підписки Supabase Pro ($25) і ElevenLabs Creator ($22) — фіксована інфраструктура **поза лімітом**. Тому хвилини живого голосу в межах місячного пакета Creator (275 хв, лічильник `spend_months.voice_package_min_used`) рахуються **без частки ElevenLabs** (лише LLM агента + модерація); понад пакет — повністю ($0,08/хв + LLM). Розмір пакета й ціна — у `model_prices`.
- **Оцінка на кожен виклик:** `ai_calls.cost_usd` = токени × ціна з `model_prices` (+ кеш), TTS — символи × ціна, голос — хвилини × ціна (з урахуванням пакета) + LLM агента. Для живого голосу — heartbeat кожні 30 с (попередня оцінка) + звірка з post-call webhook.
- **`spend_months`** (місяць за Києвом): `spent_usd`, `safety_over_limit_usd`, `state`. Інкремент — у тій самій транзакції, що й запис виклику → поріг видно одразу.
- **Стани:** `normal` → `warned` (80 %, сповіщення з прогнозом) → `budget` (100 %: сповіщення, «ШІ-друг» голосом → текст одразу; нові сесії — економ-моделі, без ескалації, без нової озвучки, без живого голосу, індексація відкладена; поточна сесія дозавершується на звичайних моделях) → `hard_stop` (110 %: нові виклики, крім безпеки й сповіщень, відхиляються; пауза уроку).
- **Відновлення:** збільшення ліміту (перерахунок стану одразу) або 1-ше число 00:00 Київ (новий рядок місяця).
- **Дитина** бачить лише «Сьогодні говоримо в чаті» / «Заняття на паузі — продовжимо пізніше» — без згадок про гроші.
- **Запобіжники в провайдерів** (передоплата без автопоповнення, бюджети) — `docs/03-resources-and-costs.md`, 4.2.

## Альтернативи
| Варіант | Чому ні |
|---|---|
| Опитування API витрат провайдерів | Затримка годинами (не виконує ≤ 1 хв), потребує адмін-ключів |
| Лише ліміти в консолях провайдерів | Немає м'якої деградації, режиму бюджету й «безпеки понад ліміт» |

## Наслідки
- Оцінка може відрізнятися від рахунків на ±10–15 % → щоденна звірка перші 2 тижні, коригування `model_prices`.
