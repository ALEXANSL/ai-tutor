# ADR-011. Джерело даних про повітряні тривоги: alerts.in.ua API (резерв — api.ukrainealarm.com)

- **Статус:** запропоновано (2026-09-25); умови використання підтверджуються при отриманні токена (S5)
- **Вимоги:** AR-10, US-14.4, 14.5, NFR-PERF-8, NFR-RES-6, A-4

## Контекст
Банер ≤ 60 с від оголошення тривоги в м. Київ; поведінка при недоступності джерела; без ШІ-витрат; тестова тривога.

## Рішення
- **alerts.in.ua API** (документація devs.alerts.in.ua, токен за запитом, Bearer-авторизація). Сервер опитує статус регіону «м. Київ» **не частіше разу на 15 с** (з урахуванням обмеження ~5 с між однаковими запитами) і кешує в `air_alert_state`.
- Планшет, поки застосунок відкритий, питає `/api/alerts/status` кожні 20 с → банер ≤ 60 с. Реальні push від джерела не потрібні.
- Джерело не відповідає > 2 хв → позначка «Немає даних про тривоги — користуйся кнопкою "Тривога"»; ручна кнопка працює завжди.
- **Резерв (опційно):** api.ukrainealarm.com (токен за формою) — підключається, якщо основне джерело виявиться нестабільним.
- Тестова тривога — тато запускає її з кабінету; запис `is_test=true`; банер показується на планшеті доньки з позначкою «ТЕСТ» (US-14.4 КП-5).
- UID регіону береться з довідника регіонів API на S5.

## Альтернативи
| Варіант | Чому ні |
|---|---|
| Парсинг Telegram-каналів | Ненадійно, порушує умови, складно |
| Неофіційні дзеркала API | Невідома стабільність |
| Лише ручна кнопка | Не виконує US-14.4 |

## Наслідки
- $0. Припущення: безкоштовне некомерційне використання — підтвердити в умовах при отриманні токена.
