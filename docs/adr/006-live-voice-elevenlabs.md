# ADR-006. Живий голос і озвучка: ElevenLabs Agents з client tools + ElevenLabs TTS

- **Статус:** запропоновано (2026-09-25); остаточне підтвердження — після спайку S13. **Оновлено 2026-09-25:** голос обирає дитина з каталогу (D-44)
- **Вимоги:** AR-6, US-1.7, 6.1, 6.2, 7.1…7.3, 8.5, 13.4, NFR-PERF-1, 2, NFR-VOICE-1…4, NFR-LANG-2, 4, R-1, PM-19

## Контекст
Дружній голос українською (жіночий — за замовчуванням; дитина може обрати жіночий або чоловічий з кількох варіантів і змінити будь-коли — D-44), однаковий у живому діалозі й озвучці; розпізнавання дитячого мовлення; затримка ≤ 1,5 с (медіана); перебивання; двомовні уроки англійської/німецької; керування екраном уроку з голосу; транскрипт у чат; модерація кожної репліки; облік хвилин.

## Рішення
- **ElevenLabs Agents** (WebRTC, `@elevenlabs/react`), агент **приватний**: сесію відкриває лише одноразовий токен від нашого сервера (після перевірки ролі, бюджету, ліміту «ШІ-друга»). API-ключ — лише на сервері.
- Промпт персони й «преамбула безпеки» — у нашому репозиторії; передаються як overrides + dynamic variables (`nickname`, `tutor_name`, `tutor_gender`, `step_context`, `language_mode`).
- **Вибір голосу дитиною (оновлення 2026-09-25):**
  - **Каталог** `tutor_voices`: розробник відбирає у Voice Library ElevenLabs (фільтр — українська) 3–4 жіночі й 3–4 чоловічі голоси (пошук 2026-09-25 підтверджує наявність обох; конкретні голоси в документах не фіксуються), генерує однакові зразки; **Алекс затверджує** ≥ 2 + 2; дитина обирає лише з затверджених. Перевага — голосам з довгим «notice period»; щотижнева перевірка `disable_at`; запасний шлях — власний голос через Voice Design.
  - **Передача в агента:** в агенті дозволено override `tts.voiceId`, промпту, першого повідомлення й словника вимови; `/api/voice/session` бере `voice_id` з каталогу на сервері й віддає разом з токеном. Зміна діє з **наступної** голосової сесії (посеред розмови голос не змінюється). Рід (`tutor_gender`) береться з голосу; поки голос не обрано — з вибору імені (`child_profile.tutor_name_gender`, docs/02 7.6.1, BUG-002).
  - **Кешована озвучка:** `audio_assets` унікальні за (`text_hash`, `voice_id`, `model`); **переозвучення за потребою** — лише кроки, що реально показуються (перший синхронно, решта — у фоні), старі файли зберігаються (повернення — $0); у режимі бюджету не переозвучується (грає попередній голос або текст); тато може обрати `keep_old`; «переозвучити все» — лише з підтвердженням **[$]**. Тексти бібліотеки не містять імені й родових форм репетитора, тож переозвучення — чисто TTS без регенерації.
  - **Вартість («Економ»):** ≈ $0–9 у перший місяць після зміни голосу (≤ 11 повторів × 8 000 символів, частково в кредитах Creator), далі менше; живий голос — без змін у ціні; зразки ≈ $0,2 разово.
- **Client tools:** `show_step`, `show_hint`, `submit_answer` (оцінку робить наш `answer_evaluation`, результат повертається агенту), `request_break`, `end_voice`. Оркестратор перевіряє кожен виклик.
- Транскрипт кожної репліки → наш сервер → `messages(voice_transcript)` + модерація. Post-call webhook (HMAC) → фінальний транскрипт, тривалість, вартість; аудіо → Storage; розмову в ElevenLabs видаляємо.
- Живий голос — **лише на діалогових кроках** і в «ШІ-другові»; пояснення — кешована озвучка. Закриття після 60 с тиші.
- **Озвучка пояснень:** ElevenLabs Multilingual v2/v3 **тим самим voice_id**, що обраний у образі; ендпойнт «with timestamps» (вирівнювання символів — для субтитрів і майбутніх губ аватара, ADR-019; якщо ціна та сама — перевірити на S12); словник вимови для нікнейму й імені репетитора (оновлюється при зміні імені); нікнейм і ім'я репетитора в аудіо бібліотеки не «запікаються».
- LLM усередині агента — швидка модель зі списку ElevenLabs, обирається в спайку S13 (якість української + затримка).
- Тариф: **Creator $22/міс** (275 хв) + докупівля $0,08/хв — **погоджено Алексом 2026-09-25**; підписка — інфраструктура поза лімітом ШІ (ADR-012).
- Ліміт живого голосу «ШІ-друга» — **10 хв/день за замовчуванням** (рішення 2026-09-25); після MVP — дешевший голос для «ШІ-друга» через `VoiceProvider` (D-4).

- **Перевірка 2026-09-25 («українська озвучка в ElevenLabs безкоштовна?»):** не підтверджено. Сторінка «Free Ukrainian Text to Speech» — рекламна сторінка **безкоштовного тарифу Free** (10 000 кредитів ≈ 10 хв аудіо/міс, 15 хв Agents/міс), однаково для всіх мов; окремої акції для української чи для українців не знайдено (партнерство з Мінцифри дає безкоштовний доступ **Мінцифрі**, не приватним користувачам). Free — некомерційний, з обов'язковою атрибуцією, а за Умовами ElevenLabs може використовувати контент для покращення сервісів → **не підходить для даних доньки** (CLAUDE.md). Рішення (Creator) і вартість не змінюються. Деталі й джерела — `docs/03` розд. 2.2.1.

## Альтернативи
| Варіант | Ціна | Чому не основний |
|---|---|---|
| Gemini Live (3.8 native audio) | ≈ $0,02–0,04/хв | Найдешевше, але підтримку української в нативному аудіо не підтверджено; кандидат на дешевший голос «ШІ-друга» (D-4) після спайку |
| OpenAI Realtime (gpt-realtime-2) | ≈ $0,10–0,25/хв | Дорожче, голоси менш природні українською, немає готових client tools/віджета — більше коду |
| Власний конвеєр STT → LLM → TTS (Scribe + Claude + TTS) | дешевше за хвилину | Складне чергування реплік, перебивання, затримка — ризик NFR-PERF-1; багато коду |
| ElevenLabs Flash v2.5 для озвучки | −50 % на озвучку | Лише якщо на демо S12 Алекс не почує різниці |
| Переозвучувати всю бібліотеку одразу при зміні голосу | до ≈ $88 за річну бібліотеку «Економу» за кожну зміну | Дорого при частих змінах; «за потребою» дає той самий результат для дитини |
| Не переозвучувати (старі уроки — старим голосом) | $0 | Порушує єдиний образ (NFR-VOICE-1); лишається як налаштування тата `keep_old` і поведінка режиму бюджету |
| Голос як змінна середовища (`ELEVENLABS_VOICE_ID`) | — | Не дозволяє вибір дитиною; замінено каталогом у БД |

## Наслідки
- Найдорожча стаття кошторису (≈ $0,10/хв повна вартість).
- План спайку S13 і запасні варіанти — `docs/02-architecture.md`, 7.4.
- Абстракція `VoiceProvider` дозволяє замінити провайдера для окремої ролі (напр., «ШІ-друг») без переробки. Каталог `tutor_voices` має поле `provider` — голос іншого провайдера для «ШІ-друга» не зламає образ, якщо зразки затвердить тато.
- Ризики: мало якісних голосів однієї статі; голос може зникнути з бібліотеки; override голосу треба дозволити в агенті (AR-R15, AR-R18 у `docs/02`).
- Деталі — `docs/02-architecture.md`, 7.6.1–7.6.3; вартість — `docs/03`, 3.9.
