# 07 — Промпт для підготовки підручників у ЖПТ (універсальний формат імпорту)

**Навіщо цей документ.** Кожен новий предмет з "повним пакетом" (як-от "Зарубіжна
література, 6 клас") раніше вимагав, щоб розробник заново вигадував схему імпорту,
бо ЖПТ щоразу повертав трохи інший формат JSON. Цей документ фіксує ОДИН
постійний контракт — промпт нижче й JSON-схему під ним — щоб той самий
імпортер (`literatureV2Import.ts` + `literature_v2_*` таблиці) міг приймати
будь-який майбутній "відкритий" (без єдиної правильної відповіді з варіантів)
предмет: зарубіжну й українську літературу, історію, правознавство, курс "Я
досліджую світ" тощо — без нової розробки щоразу.

**Коли НЕ підходить цей формат.** Для предметів із задачами на кшталт
"виберіть правильну відповідь із 4 варіантів" (математика, природничі
предмети з тестовими завданнями) є ОКРЕМИЙ формат — `course_v2_*`
(`mathCourseV2Import.ts`). Різниця: там кожне завдання має єдину правильну
відповідь (`correct_option_id`), тут — немає єдиної правильної відповіді,
лише підказки, орієнтовна відповідь, критерії оцінювання. Якщо не впевнений,
який формат підходить новому предмету — запитай розробника (мене) перед тим,
як запускати ЖПТ, одним реченням: "цей предмет — тестові завдання з
варіантами чи відкриті завдання?".

## Як користуватись

1. Скопіюй весь текст із секції **"ПРОМПТ ДЛЯ ЖПТ"** нижче.
2. Встав його в новий чат у своєму проєкті ЖПТ (той, де ти вже обробляєш
   книги), і ДОДАЙ після нього: назву підручника, клас, видавництво, рік, і
   сам файл підручника (PDF або фото сторінок).
3. Отримавши відповідь, перевір, що ЖПТ повернув **РІВНО 4 JSON-файли**
   (`course.json`, `teacher.json`, `assets.json`, `task_tables.json`) і,
   за потреби, архів ілюстрацій — **без жодних Python/SQL-скриптів і без
   "інструкції з імпорту"**: та частина нам не потрібна, наш імпортер уже
   існує.
4. Завантаж усі 4 файли (і архів ілюстрацій, якщо є) мені в чат — я перевірю
   їх нашим існуючим валідатором і за потреби повідомлю, що саме ЖПТ
   зробив не так (тоді просто попроси ЖПТ виправити конкретне поле — не
   переробляти все заново).

## ПРОМПТ ДЛЯ ЖПТ

```
Ти готуєш навчальний матеріал для ШІ-репетитора. Результат — РІВНО 4
JSON-файли з наведеною нижче структурою, і більше нічого (жодних
скриптів, інструкцій з імпорту, README). Увесь текст — українською,
крім ключів JSON (вони завжди англійською, як у прикладі).

Контекст: кожен "task" (завдання) — ВІДКРИТЕ, без єдиної правильної
відповіді з варіантів. Для нього є підказки, орієнтовна відповідь,
критерії оцінювання та типові помилки учнів — але НІКОЛИ "виберіть
варіант A/Б/В/Г". Якщо в підручнику зустрічається завдання з варіантами
відповідей — всеодно віддай його як відкрите завдання (prompt +
response_type вказує формат), без окремого поля "правильний варіант".

      "prerequisites": ["Що вже має знати — 0-2 пункти"],
      "explanation": [                            // текст пояснення теми, 2-5 абзаців

      "content_status": "ready",
      "primary_reading_pages": ["<book_id>-P007", "..."],  // САМЕ ТІ сторінки, де в підручнику текст твору/розповіді для ЦЬОГО уроку (якщо відрізняються від source_pages)

ВАЖЛИВО:
- Не вигадовуй нових полів і не перейменовуй наявні — якщо чогось не
  вистачає (напр. немає ілюстрацій), постав порожній масив/null, а не
  нове поле.
- "tts.text" завжди заповнюй — це те, що вголос прочитає ШІ-репетитор
  дитині (без скорочень на кшталт "див. мал.").
- Нумерація id має бути узгодженою: book_id — один на весь підручник;
  lesson id = book_id + "-L" + номер; task id = lesson id + "-T" + номер.
- Не додавай жодних скриптів імпорту, README чи інструкцій — лише ці 4
  JSON-файли (і архів ілюстрацій assets/*, якщо є зображення).
```

## Нотатка для розробника (себе ж, на майбутнє)

Якщо наступний предмет через цей промпт прийде з РІВНО такою структурою —
`literatureV2Import.ts`/`literatureV2Persist.ts`/`literatureV2View.ts` і
таблиці `literature_v2_*` вже вміють його прийняти без жодної зміни коду,
лише новий `subject_id` при імпорті через той самий екран у
`/parent/materials`. Єдине, що може знадобитись: перейменувати напис
панелі імпорту з "Зарубіжна література" на щось нейтральніше (напр.
"Повний пакет (відкриті завдання)"), якщо предметів стане кілька — це
косметика, не нова схема.
