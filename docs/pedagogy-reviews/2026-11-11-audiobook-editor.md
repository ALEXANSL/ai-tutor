# Аудіокниги: перевірка технічного редактора

Codex self-review, 2026-11-11. Це не незалежна людська редактура або перевірка живого API.

Мета: точно читати книгу, а не навчальний переказ. Модель може повернути тільки id/категорію очевидних коротких технічних абзаців. Вона не генерує замін для авторських слів. Сервер відхиляє неіснуючі/повторні id, великі вилучення, видалення більшості тексту й маскування числових фактів як номера сторінки. Вірші та діалоги збережені за замовчуванням. Повторювані художні рефрени автоматично не видаляються.

Ризики: короткий змістовний абзац може бути помилково класифікований; PDF з колонками/неправильним порядком текстового шару потребує редактури. Тому є видимий перелік вилучень, оригінальні абзаци, редагований сценарій і безкоштовне повернення всього тексту. Аудіо запускається тільки після погодження сценарію; перед дитячою публікацією є прослуховування. Невідомий або нерозбірливий текст не вигадується. Англомовна книга не перекладається мовчки: читання мовою джерела; переклад — майбутній окремий режим.

Перевірки: справжні синтетичні PDF/EPUB, збереження слів/пунктуації/діалогів, недопущення подвоєння overlap із пошукового індексу (джерело береться з оригіналу), точне розбиття без втрати символів, явна відповідність друкованих і фізичних сторінок. Розбір довільної верстки PDF/OCR не заявляється безпомилковим. Для першого реального запуску потрібен короткий розділ і прослуховування українського TTS.
